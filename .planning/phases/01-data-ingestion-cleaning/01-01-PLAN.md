Convention 1 — Headless matplotlib (MANDATORY, Cell 1):
  Set `os.environ['MPLBACKEND'] = 'agg'` and `os.environ['MPLCONFIGDIR'] = '/tmp/matplotlib-config'`

  Reason: The repo runs notebooks in headless CI environments; without these env vars matplotlib
  fails to initialize. This exact pattern is in notebook.ipynb cell 0967d16e.

Convention 2 — Portuguese labels for display, English for code (MANDATORY in EDA cell):
  Variable names, column names, dict keys: English (e.g., `train_df`, `home_team`, `canonical_names`).
  Chart titles, axis labels, legend text, printed summaries: Portuguese
  (e.g., `'Distribuição dos resultados (2003–2025)'`, `'Resultado'`, `'Contagem'`,
   `f"Salvo: treino={len(train_df)} linhas, teste={len(test_df)} linhas"`).

Convention 3 — Assert-then-print after every transform (MANDATORY in every data cell):
  Each transformation cell must end with at least one `assert` statement that encodes the
  expected post-condition, followed by a `print(f"...")` summarizing the resulting shape
  or key invariant. AssertionError counts as a test failure under nbmake — these inline
  asserts ARE the unit tests for this notebook.

Convention 4 — pandas 2.x date parsing:
  Use `pd.to_datetime(df['data'], format='%d/%m/%Y')` AFTER `pd.read_csv`. Do NOT pass
  `parse_dates=...` or `infer_datetime_format=True` to `read_csv` — both are deprecated in
  pandas 2.x. Do NOT call `df.sort_values('data')` on the raw string column — DD/MM/YYYY
  sorts lexicographically wrong. Assert `df['date'].is_monotonic_increasing` after parsing.

Convention 5 — Drop unused columns by name, never use `df.dropna()`:
  `formacao_mandante` (4,975 nulls), `formacao_visitante` (4,975), `tecnico_mandante` (4,610),
  `tecnico_visitante` (4,610), and `arrecadacao` (8,785) have many missing values.
  `df.dropna()` would drop ~96% of rows. Drop these columns explicitly via column selection;
  the columns kept in the output have 0 nulls (verified).
